Request flow (one issue)

  1. scan() — fetch payments / disputes / refunds / orders
  2. diagnose() — AI or rules decide what happened
  3. decide() — check your rules (boundary enforcer)
  4. execute() — capture / retry link / contest / refund / message
  5. audit() — write plain-English log entry
